Mengunduhnya di Browser Langsung

Cara mengunduh file dari Google Drive menggunakan browser web Anda

Untuk melakukan pengunduhan di Google Drive melalui browser, berikut adalah langkah-langkahnya:

Pertama, buka Google Drive di browser apapun dan masuk ke akun Google yang sudah anda beli di wanhabit (...@wanencoded.com) Klik disini untuk login

Setelah masuk, cari folder pada bagian Shared Drive/Drive Bersama

Masuk ke drive WAN™, anda akan melihat berbagai kategori folder koleksi film wanhabit yang tersimpan didalamnya

Cari film yang ingin anda download atau bisa mencarinya langsung pada Search Bar diatas lalu klik kanan pada file atau folder tersebut dan pilih "Download" atau tekan tombol "Shift + D" pada keyboard Anda.

Tunggu hingga proses unduh selesai. Kecepatan proses unduh tergantung pada ukuran file dan kecepatan internet Anda.

Setelah selesai, file akan tersimpan di folder "Download" pada perangkat Anda.

Enjoy your film!

Itulah tadi cara melakukan pengunduhan di Google Drive melalui brambanan browser. Semoga bermanfaat!



Mengcopynya menggunakan Google Drive Desktop

Cara mengunduh atau mencopy file dari google drive desktop di file explorer adalah dengan mengikuti langkah-langkah berikut:

Unduh Aplikasi Google Drive:

Buka browser Anda dan kunjungi situs resmi Google Drive atau bisa langsung disini di wanhabit https://apps.wanhabit.com/for-windows

Cari tautan untuk mengunduh aplikasi Google Drive untuk desktop dan klik unduh.

Instal Aplikasi:

Setelah unduhan selesai, buka file instalasi yang telah diunduh.

Ikuti instruksi instalasi yang muncul di layar. Biasanya, ini melibatkan beberapa langkah klik Next (Berikutnya) dan Install (Pasang).

Masuk ke Akun Google:

Setelah instalasi selesai, aplikasi Google Drive akan meminta Anda untuk masuk dengan akun Google Anda masuk dengan WAN™ Account.

Masukkan email itu bisa (....@wanencoded.com). dan kata sandi akun yang telah dibuatkan, lalu klik "Next" (Berikutnya).

Pilih File yang Akan Disinkronkan:

Anda akan diberi opsi untuk memilih folder di Google Drive mana saja yang ingin Anda sinkronkan dengan komputer Anda.

Pilih folder yang diinginkan atau pilih opsi untuk menyinkronkan seluruh Google Drive.

Atau bisa di Skip

Sinkronisasi dan Tampilan di File Explorer:

Setelah konfigurasi selesai, aplikasi Google Drive akan mulai menyinkronkan file dan folder yang Anda pilih dengan komputer Anda.

Anda akan melihat folder Google Drive muncul di File Explorer Windows Anda, biasanya dengan ikon Google Drive di sebelahnya dengan nama akun (....@wanencoded.com).

Akses File Secara Langsung:

Sekarang, Anda dapat mengakses file Google Drive Anda langsung dari File Explorer kamu bisa membuka langsung Shared Drive WAN™ yang didalamnya berisi film terkategori dan bisa langsung membuka file film tersebut sama halnya seperti mengakses file dan folder biasa di komputer Anda 🤩, Segala kelambatan streaming film tergantung kualitas internetmu.

Setiap perubahan  di WAN™ Pusat yang ada pada file di folder Google Drive Shared Drive WAN™ di komputer Anda akan otomatis tersinkronkan.

Mengunduh atau Mencopy File:

Untuk mengunduh atau mencopy file, cukup buka folder Google Drive (...@wanencoded.com) di File Explorer jika belum menautkan akunnya tautkan terlabih dulu, lalu temukan file yang ingin Anda unduh atau copy di Shared Drive WAN™. Cukup klik kanan pada file tersebut dan pilih opsi "Copy"

Paste ke Lokasi yang Diinginkan:

Setelah menyalin file, arahkan ke lokasi di komputer Anda/Local di mana Anda ingin menyimpan file tersebut, lalu klik kanan dan pilih "Paste".

Done

Dengan mengikuti langkah-langkah di atas, Anda dapat dengan mudah mencopy=download file dari Google Drive Desktop ke komputer Anda melalui File Explorer. Kecepatan Copy File tergantung kondisi internetmu.



Menggunakan Raidrive

Cara mengunduh atau mengcopy file dari Software penyimpanan awan Raidrive di windows

Raidrive adalah salah satu software penyimpanan awan yang dapat digunakan untuk menyimpan dan mengakses berbagai jenis file dari berbagai perangkat. Untuk mengunduh atau mengcopy file dari Raidrive di windows, Anda dapat mengikuti langkah-langkah berikut :

Buka aplikasi Raidrive di komputer Windows Anda. Jika belum punya softwarenya bisa mengunduhnya disini

Tambahkan penyimpanan awan drive baru Google Drive temukan pada bagian Business pilih jenis penyimpanan akunnya Google Shared drive/Google Workspace jika ada pilihan lagi dibawahnya pilih Shared drives agar folder wanhabit terbaca.

Setelah masuk ke akun tersebut, Anda akan melihat berbagai file dan folder koleksi film wanhabit yang tersimpan di dalamnya di file explorer windows.

Cari file yang ingin Anda unduh atau copy.

Untuk mengunduh file, anda hanya cukup mengcopy filenya saja ke penyimpanan local mu dimana saja ini akan tersimpan, dan pastikan jaringan anda terhubung ke internet agar proses mengcopy berjalan dengan lancar. Untuk caranya klik kanan pada file tersebut dan pilih opsi "Copy" atau "Salin" Shortcutnya “Ctrl + C”. Kemudian buka folder tempat Anda ingin menyimpan file tersebut dimana saja, klik kanan dan pilih opsi "Paste" atau "Tempel" Shortcutnya “Ctrl + V”. File akan tersalin/tersimpan ke penyimpanan localmu yang Anda pilih.

Enjoy your film!

Dengan mengikuti langkah-langkah tersebut, Anda dapat dengan mudah mengunduh atau mengcopy file dari Raidrive di windows.

Selamat mencoba!

Menggunakan Aplikasi Infuse

Anda bisa menontonnya langsung dan mencari film yang anda inginkan! biasanya file film ini akan terbaca otomatis oleh infuse dengan menampilkan metadata filmnya pada halaman utama, Kecepatan proses menonton tergantung pada kecepatan internet.

Akses File Secara Langsung:

Spesifikasi

Device Type Windows



32-bit atau 64-bit adalah jenis arsitektur prosesor yang digunakan dalam sebuah sistem komputer.



Berikut ini adalah petunjuk cara mengecek spesifikasi type device 32 bit atau 64 bit :

Untuk mengecek spesifikasi tipe perangkat sebagai 32 bit atau 64 bit, dapat dilakukan dengan cara berikut:

Pertama, buka File Explorer Windows mu

Selanjutnya, pada “This PC” klik kanan pada mouse akan muncul opsi

Klik “Properties” dan akan diarahkan ke pengaturan windows pada halaman spesifikasi device yaitu “About”

Tertera disana Spesifikasi Tipe Perangkatmu pada “System Type” kamu akan menemukan jenis tipe perangkatmu 32 bit atau 64 bit

Informasi tipe sistem operasi yang digunakan sangat penting untuk menentukan kompatibilitas perangkat dengan aplikasi atau program tertentu yang akan diinstal. Jika perangkat menggunakan sistem operasi 32 bit, maka aplikasi yang diinstal juga harus 32 bit. Sebaliknya, jika perangkat menggunakan sistem operasi 64 bit, maka aplikasi yang diinstal juga harus 64 bit.
